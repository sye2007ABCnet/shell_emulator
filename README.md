# Эмулятор языка оболочки ОС (вариант №19)

## Общее описание

Эмулятор командной строки, имитирующий работу в UNIX-подобной ОС. 
Реализован на Python 3 (стандартная библиотека, без внешних 
зависимостей). Поддерживает конфигурацию через параметры
командной строки, виртуальную файловую систему (VFS), полностью
работающую в памяти, и набор команд UNIX-подобной оболочки.

Разработка ведётся поэтапно: реализованная на каждом этапе
функциональность описана по порядку в разделе "Функции и настройки"
ниже.

## Функции и настройки

На этапе 1 реализовано:

- REPL-цикл (чтение команды → выполнение → печать результата).
- Приглашение к вводу вида `vfs> ` (имя VFS пока фиксировано).
- Раскрытие переменных окружения реальной ОС в аргументах команд
  (`$HOME`, `${HOME}` и т.п.).
- Команды-заглушки `ls`, `cd` — выводят своё имя и полученные
  аргументы.
- Команда `exit` — завершает работу.
- Обработка ошибок: неизвестная команда, неверные аргументы,
  некорректный синтаксис ввода (например, незакрытая кавычка).

На этапе 2 реализовано:

- `--vfs-path ПУТЬ` — путь к физическому расположению VFS; имя VFS
  в приглашении берётся из имени файла.
- `--prompt СТРОКА` — пользовательское приглашение к вводу (полностью
  заменяет значение по умолчанию).
- `--script ПУТЬ` — путь к стартовому скрипту; поддерживает
  комментарии (строки, начинающиеся с `#`). При выполнении на экране
  видны и вводимые команды, и их результат. Ошибка в отдельной строке
  скрипта не прерывает выполнение остальных.
- При запуске всегда печатается отладочный вывод всех параметров
  конфигурации.

На этапе 3 реализовано:

- VFS загружается из JSON-файла (`--vfs-path`), полностью в память.
- Формат узла: `name`, `type` (`file`/`dir`), опционально `permissions`,
  `content` (base64, для файлов) или `children` (список узлов, для
  директорий).
- Исходный JSON-файл никогда не изменяется и не распаковывается на
  диск.
- Ошибка загрузки (файл не найден, некорректный JSON, неверная схема)
  не приводит к падению эмулятора — выводится сообщение, и работа
  продолжается с пустой VFS.
- Примеры VFS разной сложности — в `fixtures/vfs/`.

## Сборка и запуск тестов

Проект не требует сборки (интерпретируемый Python, зависимостей нет).

```bash
make run    # запустить эмулятор
make test   # прогнать тесты
```

## Примеры использования

```
Для этапа 1:

$ make run
Эмулятор командной строки. VFS: vfs
Введите 'exit' для выхода.

vfs> ls -la /home
ls: аргументы=['-la', '/home']
vfs> cd $HOME
cd: аргументы=['/home/user']
vfs> unknowncmd arg1 arg2
unknowncmd: команда не найдена
vfs> exit extra_arg
ошибка: exit: команда не принимает аргументов
vfs> exit


Для этапа 2:

$ python3 src/emulator.py --vfs-path /tmp/example.json --prompt "myos:~$ "
Параметры конфигурации эмулятора:
  путь к VFS       : /tmp/example.json
  имя VFS          : example
  приглашение      : 'myos:~$ '
  стартовый скрипт : (не задан)

Эмулятор командной строки. VFS: example
Введите 'exit' для выхода.

myos:~$ ls
ls: аргументы=[]


Для этапа 3:

$ python3 src/emulator.py --vfs-path fixtures/vfs/deep_structure.json --prompt "demo:/$ "
Параметры конфигурации эмулятора:
  путь к VFS       : fixtures/vfs/deep_structure.json
  имя VFS          : deep_structure
  приглашение      : demo:/$ 
  стартовый скрипт : (не задан)

ошибка загрузки VFS: /deep_structure/level1/l1.txt: некорректные данные base64 (Only base64 data is allowed)
Эмулятор командной строки. VFS: deep_structure
Введите 'exit' для выхода.

demo:/$ ls
ls: аргументы=[]
demo:/$ exit


python3 src/emulator.py --vfs-path fixtures/vfs/does_not_exist.json
Параметры конфигурации эмулятора:
  путь к VFS       : fixtures/vfs/does_not_exist.json
  имя VFS          : does_not_exist
  приглашение      : does_not_exist> 
  стартовый скрипт : (не задан)

ошибка загрузки VFS: не удалось открыть файл VFS 'fixtures/vfs/does_not_exist.json': [Errno 2] No such file or directory: 'fixtures/vfs/does_not_exist.json'
Эмулятор командной строки. VFS: does_not_exist
Введите 'exit' для выхода.

does_not_exist> exit
```
