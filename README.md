# Эмулятор языка оболочки ОС (вариант №19)

## Общее описание

Эмулятор командной строки, имитирующий работу в UNIX-подобной ОС.
Реализован на Python 3 (стандартная библиотека, без внешних
зависимостей). Разработка ведётся поэтапно; текущий этап — 1
(минимальный прототип REPL).

## Функции и настройки

На этапе 1 реализовано:

- REPL-цикл (чтение команды → выполнение → печать результата).
- Приглашение к вводу вида `vfs> ` (имя VFS пока фиксировано).
- Раскрытие переменных окружения реальной ОС в аргументах команд
  (`$HOME`, `${HOME}` и т.п.).
- Команды-заглушки `ls`, `cd` — выводят своё имя и полученные
  аргументы.
- Команда `exit` — завершает работу.
- Обработка ошибок: неизвестная команда, неверные аргументы,
  некорректный синтаксис ввода (например, незакрытая кавычка).

На этапе 2 реализовано:

- `--vfs-path ПУТЬ` — путь к физическому расположению VFS; имя VFS
  в приглашении берётся из имени файла.
- `--prompt СТРОКА` — пользовательское приглашение к вводу (полностью
  заменяет значение по умолчанию).
- `--script ПУТЬ` — путь к стартовому скрипту; поддерживает
  комментарии (строки, начинающиеся с `#`). При выполнении на экране
  видны и вводимые команды, и их результат. Ошибка в отдельной строке
  скрипта не прерывает выполнение остальных.
- При запуске всегда печатается отладочный вывод всех параметров
  конфигурации.

## Сборка и запуск тестов

Проект не требует сборки (интерпретируемый Python, зависимостей нет).

```bash
make run    # запустить эмулятор
make test   # прогнать тесты
```

## Примеры использования

```
Для этапа 1:

$ make run
Эмулятор командной строки. VFS: vfs
Введите 'exit' для выхода.

vfs> ls -la /home
ls: аргументы=['-la', '/home']
vfs> cd $HOME
cd: аргументы=['/home/user']
vfs> unknowncmd arg1 arg2
unknowncmd: команда не найдена
vfs> exit extra_arg
ошибка: exit: команда не принимает аргументов
vfs> exit


Для этапа 2:

$ python3 src/emulator.py --vfs-path /tmp/example.json --prompt "myos:~$ "
Параметры конфигурации эмулятора:
  путь к VFS       : /tmp/example.json
  имя VFS          : example
  приглашение      : 'myos:~$ '
  стартовый скрипт : (не задан)

Эмулятор командной строки. VFS: example
Введите 'exit' для выхода.

myos:~$ ls
ls: аргументы=[]
```
